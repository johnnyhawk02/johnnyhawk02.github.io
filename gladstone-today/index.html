Gladstone: today at a glance

A bookmark button that shows today's classes and gym bookings for every room in one view, using your own signed-in Gladstone tab.

Install (once)

  1. Show your bookmarks bar in Chrome (Ctrl+Shift+B, or Cmd+Shift+B on a Mac).
  2. Drag this button onto the bookmarks bar: Gladstone today

Use

  1. Sign in to Gladstone and open Centre Management as normal.
  2. Click Gladstone today on the bookmarks bar. It switches to today and reads each room (pool rooms are skipped).
  3. Use the Classes / Gym switch to flip between views. Click Refresh for the latest numbers.

Easiest on a tablet: automatic button

This adds a Today view button to the corner of Gladstone, so there's nothing to paste.

  1. iPad: install the free Userscripts app from the App Store and turn it on in Safari (aA menu, then Manage Extensions). Android: install Firefox, then add the Tampermonkey add-on from Firefox's Extensions menu.
  2. Open this page in that browser and tap Install Gladstone today, then confirm.
  3. Open Centre Management and tap Today view at the bottom right.

Or: paste a bookmark

Tablets can't drag buttons, so you paste the code into a bookmark instead:

  1. Tap Copy code below.
  2. Bookmark any page (for example this one) and name it Gladstone today.
  3. Edit that bookmark and replace its address with the copied code. On an iPad that's Bookmarks, then Edit, then tap the bookmark. In Chrome on Android, tap the star, then Edit.
  4. To use it, open Centre Management, tap the address bar, type Gladstone today and tap the bookmark that appears. On an iPad you can also open it from the Bookmarks list.

It only reads what your login can already see. Nothing is sent anywhere, and nothing is booked or changed. If Gladstone updates its screens, the button may need a tweak.
