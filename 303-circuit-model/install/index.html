Install 303 Circuit Model

A free acid bass synth, modelled part by part from the original 1982 bass line circuit. This page walks you through installing it, even if you have never typed a command before.

It works as a plug-in: an extra instrument that opens inside your music software. Music software like this is often called a DAW (digital audio workstation), for example Ableton Live, Logic Pro, FL Studio, Reaper, Bitwig, Cubase or GarageBand.

Want to hear it first? It also runs in your web browser. Nothing to install.

Try it in your browser →

Pick your computer

Works on Apple Silicon and Intel Macs running macOS 11 or later. You get two versions of the plug-in, VST3 and AU. They are just two plug-in formats; your music software picks the one it uses (Logic Pro and GarageBand use AU).

The install command

curl -fsSL https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.sh | bash
  1. Open Terminal: press Cmd + Space, type Terminal, press Return. A window with a blinking cursor opens. That is all Terminal is: a place to type commands.
  2. Click Copy on the install command above.
  3. Click in the Terminal window, then paste with Cmd + V.
  4. Press Return. You'll see "Downloading 303 Circuit Model..." and a progress bar. Nothing needs typing, and no password is asked for.
  5. When it says Done., close Terminal.

    A drawing, so your window may look a little different.

  6. Open your music software and rescan plug-ins (see Find it in your DAW below).

What the command does

It downloads the plug-in from my GitHub releases and copies it into your own plug-in folders, in your user Library:

~/Library/Audio/Plug-Ins/VST3/303 Circuit Model.vst3
~/Library/Audio/Plug-Ins/Components/303 Circuit Model.component

No password is asked for, and nothing else on your Mac is changed. Running it again is safe: it just updates to the newest version.

Works on Windows 10 or 11, 64-bit. You get the VST3 version, a plug-in format every Windows music app understands.

The install command

irm https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.ps1 | iex
  1. Open PowerShell: click Start, type PowerShell, press Enter. A blue or black window opens. Don't pick "Run as administrator"; the installer asks for permission itself.
  2. Click Copy on the Windows command above.
  3. Right-click inside the PowerShell window to paste (or press Ctrl + V).
  4. Press Enter.
  5. When Windows asks "Do you want to allow this app to make changes to your device?", click Yes.
  6. When it says Done., close PowerShell and rescan plug-ins in your DAW (see Find it in your DAW below).

    A drawing, so your window may look a little different.

What the command does

It downloads the plug-in from my GitHub releases and copies it into the folder every DAW looks in:

C:\Program Files\Common Files\VST3\303 Circuit Model.vst3

That folder belongs to Windows, which is why it shows one "allow this app to make changes" box. Nothing else is changed. Running it again is safe: it just updates to the newest version.

The plug-in's screen needs the Microsoft Edge WebView2 Runtime. Windows 11 and up-to-date Windows 10 already have it. If yours doesn't, the installer tells you, and you can get it free from Microsoft's WebView2 page (choose the Evergreen Bootstrapper).

Works on 64-bit Linux (x86_64). You get the VST3 version.

The install command

curl -fsSL https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.sh | bash
  1. Open your terminal app. On many systems Ctrl + Alt + T does it.
  2. Click Copy on the install command above, then paste it into the terminal with Ctrl + Shift + V.
  3. Press Enter.
  4. If it says WebKitGTK is missing, run the command it prints (see below), then you're set.
  5. When it says Done., close the terminal and rescan plug-ins in your DAW.

What the command does

It downloads the plug-in from my GitHub releases and copies it to ~/.vst3/303 Circuit Model.vst3. Nothing else is changed, and running it again just updates to the newest version.

The plug-in's screen needs WebKitGTK 4.1. If it's missing, the installer says so and prints the command for your system:

Debian / Ubuntu

sudo apt install libwebkit2gtk-4.1-0

Fedora

sudo dnf install webkit2gtk4.1

Arch

sudo pacman -S webkit2gtk-4.1

Why a command, not a normal download?

The plug-in is free, and I haven't paid Apple's yearly fee to have it notarised (checked and signed off by Apple). A Mac blocks un-notarised plug-ins downloaded in a web browser and calls them "damaged". Downloaded with the command, it isn't blocked.

The command only downloads the plug-in from my GitHub releases and copies it into the plug-in folder. If you'd like to read the scripts before you run them, here they are: install.sh (Mac and Linux) and install.ps1 (Windows).

There are no accounts and no tracking, and your presets stay on your computer.

Find it in your DAW

  • Ableton LiveSettings > Plug-ins, turn on "Use VST3 Plug-in System Folders", click Rescan. It's under Plug-ins > 303 Circuit.
  • Logic Pro / GarageBandIt appears under Audio Units > 303 Circuit > 303 Circuit Model. If not, restart Logic.
  • FL StudioOptions > Manage plugins > Find plugins.
  • ReaperOptions > Preferences > Plug-ins > VST > Re-scan.
  • Bitwig, Cubase, Studio One and othersRescan or restart; it's listed as "303 Circuit Model" by "303 Circuit".

Add it to an instrument track. Press play in the DAW: the plug-in follows the DAW's play, stop and tempo.

Updating

Run the same install command again (pick your computer above). It replaces the plug-in with the newest version. Your presets are kept.

Uninstalling

Mac and Linux

Paste this into Terminal and press Return (or Enter):

curl -fsSL https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.sh | bash -s -- --uninstall

Windows

In File Explorer, delete this folder. Windows asks for permission; click Continue.

C:\Program Files\Common Files\VST3\303 Circuit Model.vst3

Presets

Uninstalling keeps your presets. To remove them too, delete this folder:

  • Mac~/Library/Application Support/303 Circuit Model
  • Windows%APPDATA%\303 Circuit Model
  • Linux~/.config/303 Circuit Model

Trouble?

Nothing shows up in my DAW

Make sure your DAW is 64-bit and scans the standard VST3 folder, then rescan. If it's still missing, restart the DAW.

The plug-in window is blank

Windows: install the Microsoft Edge WebView2 Runtime (the Evergreen Bootstrapper), then reopen the plug-in.

Linux: install WebKitGTK 4.1 (the commands are in the Linux steps).

My Mac says it's "damaged"

You downloaded the zip in a web browser. Use the Terminal command instead; that copy isn't blocked. (Why?)

"command not found: curl" (Linux, very rare)

Install curl with your system's package manager, then run the install command again.
